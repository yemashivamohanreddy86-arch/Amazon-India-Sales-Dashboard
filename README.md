# Amazon India Sales Dashboard

## Project Overview

An interactive Amazon India Sales Dashboard built using Microsoft Power BI to analyze sales, profit, orders, products, payment methods, fulfillment, order status, and geographic performance.

The dashboard is designed to provide management with a clear and interactive overview of business performance.

## Objectives

- Analyze overall sales and profit performance
- Track total orders and units sold
- Monitor average order value and profit margin
- Analyze monthly sales and profit trends
- Compare category-wise sales, profit, and units sold
- Identify the top 10 products by sales
- Analyze order status and revenue loss
- Monitor return and cancellation rates
- Compare payment and fulfillment methods
- Analyze state-wise sales, profit, and orders
